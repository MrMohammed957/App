# MonitorApp

## خطوات الحصول على ملف APK عبر GitHub Actions

1. افتح github.com وسجّل دخول.
2. اعمل Repository جديد (زر New)، خليه Private، واختار أي اسم (مثلاً `monitor-app`). لا تضف README أو .gitignore تلقائي.
3. ارفع كل محتويات هذا المجلد (بما فيها مجلد `.github` المخفي) للريبو:
   - أسهل طريقة: نزّل تطبيق **GitHub Desktop**، سجّل دخول، اختار "Add Local Repository" وحدد هذا المجلد، ثم اضغط "Publish repository".
4. بعد الرفع، روح لتبويب **Actions** في صفحة الريبو على GitHub. هتلاقي عملية بناء (workflow) شغالة اسمها "Build APK".
5. استنى لحد ما تخلص (علامة ✅ خضرا)، حوالي 3-5 دقائق.
6. دوس على العملية اللي خلصت، وتحت هتلاقي قسم **Artifacts**، فيه ملف اسمه `app-debug-apk` — نزّله، هيجيلك كملف zip فيه الـ APK جواه.
7. فك الضغط، انقل `app-debug.apk` لموبايل ابنك، وثبّته (هيطلب السماح بالتثبيت من مصادر غير معروفة لأنه مش من متجر Google Play).

## ملاحظة
كل مرة تعدّل فيها أي ملف كود وترفعه تاني (push)، GitHub هيبني نسخة APK جديدة تلقائيًا بنفس الطريقة.
